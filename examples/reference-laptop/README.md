# Reference laptop profile

This example documents the single-radio standalone AP deployment. It uses exclusive client/AP mode: `nigel-hotspot off` restores the existing client connection, and `nigel-hotspot on` enables the hotspot.

Do not copy Wi-Fi credentials into this directory. Keep the existing client credentials in `/etc/wpa_supplicant.conf` and provide the AP passphrase interactively during `setup.sh enable-hotspot`.
